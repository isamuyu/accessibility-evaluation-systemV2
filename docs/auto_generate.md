# 自动带出评价项功能说明

## 功能概述

系统现在支持**自动带出评价项**，根据建筑类型自动预加载所有需要评价的控制项、系统评分项和设施评分项，无需人工逐条录入。

## 使用方法

### 1. 创建建筑时自动生成

创建建筑后，系统会自动：
- ✅ 生成该建筑类型对应的**控制项清单**
- ✅ 生成该建筑类型对应的**系统评分项**
- ✅ 用户只需填写实际得分和核查结果

### 2. 添加设施时自动生成

添加设施（如轮椅坡道、无障碍电梯）后，系统会自动：
- ✅ 根据设施类别生成对应的**设施评分项**
- ✅ 包含标准条文号、满分值、评价描述

## 建筑类型与自动生成内容对照

| 建筑类型 | 控制项 | 系统评分项 | 设施类别 |
|---------|--------|-----------|---------|
| 🏠 住宅类 | Q1(5条)+Q3(6条)+Q4(3条)=14条 | Q1+Q3+Q4+施工+运维=45条 | 通道、坡道、电梯等+居室、无障碍卫生间 |
| 🏢 非住宅类 | Q1(5条)+Q2(5条)+Q3(6条)+Q4(3条)=19条 | Q1+Q2+Q3+Q4+施工+运维=约55条 | 全部13类设施 |
| 🏨 含住宿公建 | 同上 | 同上 | 全部13类设施 |
| 🏬 不含住宿公建 | Q1(5条)+Q2(5条)+Q4(3条)=13条 | Q1+Q2+Q4+施工+运维=约45条 | 不含居室、无障碍卫生间 |

## 数据规模

- **标准控制项**：19条（覆盖Q1-Q4）
- **标准系统评分项**：45条（Q1=18条、Q4=19条、施工验收=7条、运行维护=5条）
- **标准设施评分项**：
  - 无障碍通道：8条
  - 轮椅坡道：7条
  - 无障碍出入口：8条
  - 门：12条
  - 无障碍电梯：8条
  - 盲道：9条
  - 其他通行设施：9条
  - 公共卫生间：11条
  - 无障碍厕所：11条
  - 居室：10条
  - 无障碍卫生间：5条

## 操作示例

### 示例1：创建住宅类建筑
```
1. 点击"添加建筑"
2. 选择"住宅类居住建筑"
3. 填写建筑名称和面积
4. 点击"创建"
5. 系统自动生成：
   - 14条控制项（Q1、Q3、Q4）
   - 45条系统评分项
6. 进入评分页面即可看到所有待评价项
```

### 示例2：添加无障碍电梯
```
1. 在设施评分页面点击"添加设施"
2. 选择类别"[Q1] 无障碍电梯"
3. 填写设施名称和位置
4. 点击"添加"
5. 系统自动生成8条电梯评分项：
   - 5.3.5.1a 轿厢饰面（1分）
   - 5.3.5.1b 轿厢照度（1分）
   - 5.3.5.2 轿厢尺寸（3分）
   - ...
6. 只需逐条填写实际得分即可
```

## 预填数据说明

自动生成的评价项默认状态：
- **控制项**：is_compliant = null（待检查）
- **系统评分项**：actual_score = 0（待评分），applicable_score = max_score（默认参评）
- **设施评分项**：actual_score = 0（待评分）

用户只需：
1. 控制项：勾选是否达标，填写核查结果
2. 评分项：填写实际得分
3. 不参评项：将 applicable_score 设为 0 或标记为不参评

## 优势

✅ **减少录入工作量**：无需手动输入条文号
✅ **避免遗漏**：自动带出所有应评价项
✅ **标准统一**：使用标准条文号和满分值
✅ **智能过滤**：根据建筑类型自动过滤不参评项
